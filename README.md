# 数字时空 · 十四行诗终端
> interactive‑poem‑terminal

纯前端交互诗歌演示项目，零后端依赖，浏览器直接打开即可运行。

## ✨项目介绍
赛博风格沉浸式诗歌交互终端。
点击每一行诗句，星空背景切换氛围色调，同时终端框输出对应诗意文本。

- 📄单文件项目，仅 index.html，开箱即用
- 🌌Canvas动态星空粒子动画
- 📝点击诗句输出对应诗意文案
- 📱完整适配手机浏览器
- 🚀支持GitHub Pages一键部署在线演示

## 🚀快速运行
1.本地：下载`index.html`，浏览器双击打开直接体验。
2.GitHub Pages部署：
仓库 Settings → Pages → Source选择main分支，根目录，保存，等待生成公开链接。

本地直接双击打开会有浏览器安全限制，推荐GitHub Pages部署，或者本地用Live Server之类服务打开，避免其他人拿到源码本地打开误以为白屏失效。
