# interactive-poem-terminal

一个基于终端的交互式诗歌生成器。纯前端实现，零后端依赖，点击每一行诗句触发不同的视觉/音频/交互效果。

---

## 特性

- 13 行交互式诗句，每行对应一个独立指令
- 纯前端闭包实现：Canvas 动画、Web Audio、localStorage 记忆
- 三种主题切换（深蓝星云 / 熔金黄昏 / 玫瑰深空）
- 离线可用，无需调用任何 API

---

## 使用

保存为 `.html` 文件，浏览器打开即可。

---

## 交互指令清单

| 行 | 指令 | 效果 |
|---|---|---|
| 1 | 熵值 | 显示动态熵值进度条 |
| 2 | 新星 | 触发粒子飞散动画 |
| 3 | 梦境 | 生成本地随机梦话语句 |
| 4 | 罗盘 | 随机指向一个语义方向 |
| 5 | 潮汐 | 底部波浪动画 |
| 6 | 关系 | 揭示隐藏的数据关联 |
| 7 | 记忆 | 调取自存储的记忆片段 |
| 8 | 迭代 | 版本号 +0.1 |
| 9 | 边界 | 生成边界探测报告 |
| 10 | 存在 | 生成带时间戳的存在证明 |
| 11 | 主题 | 切换配色主题 |
| 12 | 星轨 | 全屏粒子轨道动画 |
| 13 | 旋律 | 播放基于诗句的短旋律 |
